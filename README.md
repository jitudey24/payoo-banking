# Payoo Banking

A mobile-style banking interface practice project. The current page presents a login screen with mobile number and PIN inputs.

## Features
- Banking-themed login interface
- Mobile number input
- Four-digit PIN input
- Responsive card-style layout
- Tailwind CSS and DaisyUI styling

## Technologies
- HTML5
- Tailwind CSS
- DaisyUI

## Run Locally
1. Clone this repository.
2. Open `index.html` in a modern browser.
3. The page loads Tailwind CSS and DaisyUI from their CDNs, so an internet connection is required for those styles.

## Project Purpose
This project practices building a simple banking login interface and working with utility-first CSS classes.
